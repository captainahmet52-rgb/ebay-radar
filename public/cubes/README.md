# Küp görselleri

Ana sayfadaki platform kartlarında kullanılan 3D küp görselleri buraya konur.

Beklenen dosyalar (şeffaf arka planlı PNG önerilir):

- `amazon.png` — Amazon küpü
- `ebay.png`   — eBay küpü
- `etsy.png`   — Etsy küpü

Öneriler:
- Kare oran (örn. 512×512 veya 1024×1024)
- Şeffaf arka plan (PNG)
- Küpün altındaki parlama/halka görselin içinde olabilir; kod ayrıca hafif bir
  parlama daha ekler.

Dosyalar yoksa kod otomatik olarak basit bir kutu + harf gösterir (site bozulmaz).
